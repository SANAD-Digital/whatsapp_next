## إعادة التصوير

السكربتات في مجلد الجلسة المؤقت. للتكرار:

1. شغّل `python3 -m http.server 8765` من `apps/whatsapp_next/docs/` (للنماذج).
2. استخدم Playwright من `apps/crm/node_modules/playwright` مع Chromium في `~/.cache/ms-playwright/chromium-1248/`.
3. حدّد `locale: "ar-SA"` و`?_lang=ar` لصفحات المنصة.
4. ثبّت خط Noto Color Emoji في `~/.local/share/fonts/emoji/` حتى تظهر الإيموجي.
